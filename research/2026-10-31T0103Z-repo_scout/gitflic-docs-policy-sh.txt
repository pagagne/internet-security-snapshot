Введение
В настоящем документе содержатся основные положения лицензирования программного обеспечения GitFlic компании ООО «РеСолют». Документ также включает термины, которые описывают условия использования Программного обеспечения и регулируют это использование.
ООО «РеСолют» является правообладателем на основании свидетельства о государственной регистрации программы для ЭВМ № 2021667729.
Доступность тех или иных Лицензий на Программное обеспечение и сертификатов определяется соответствующим Прайс-листом.
ООО «РеСолют» оставляет за собой право на изменение настоящего документа без предварительного уведомления. Актуальная версия документа доступна по адресу: https://gitflic.ru/docs/policy-sh .
Настоящий документ является собственностью ООО «РеСолют» и защищён законодательством Российской Федерации и международными соглашениями об авторских правах и интеллектуальной собственности.
Копирование документа либо его фрагментов в любой форме, распространение, в том числе в переводе, а также их передача третьим лицам возможны только с письменного разрешения ООО «РеСолют».
1. Глоссарий
Компания – общество с ограниченной ответственностью «РеСолют», ИНН 9704054697, являющееся правообладателем Программного обеспечения.
Пользователь – лицо, которому предоставлено право использования ПО для собственных нужд либо в пределах иной прямо согласованной модели использования.
Лицензионное соглашение с Конечным пользователем (EULA) – лицензионное соглашение между Компанией и Конечным пользователем, определяющее условия использования Программного обеспечения Конечным пользователем.
Лицензия – право использования ПО на условиях простой (неисключительной) лицензии способами и в пределах, прямо предусмотренных Соглашением и договором.
Обновление – набор (пакет) исправлений (патчей) к ПО, предназначенный для устранения дефектов, и/или оптимизации работы ПО и/или предоставления дополнительных функциональных возможностей с/без перехода на новую минорную версию ПО.
Программное обеспечение (ПО) – программное обеспечение GitFlic (в том числе предыдущие и (или) альтернативные наименования ПО, указанные в реестре отечественного программного обеспечения), включая его модули, компоненты, обновления, исправления, документацию и иные материалы, предоставленные Компанией в связи с использованием ПО. Наименование ПО указывается в договоре.
Партнер (Реселлер) – юридическое лицо или индивидуальный предприниматель, которому Компания предоставила право распространять ПО, предоставлять сублицензии и/или оказывать сопутствующие услуги в пределах прав, предоставленных Компанией.
Работник - физическое лицо, которое состоит в трудовых отношениях с Пользователем.
Узел - физический или виртуальный сервер, на котором используется ПО.
2. Общие положения
Программа для электронных вычислительных машин GitFlic предназначена для обеспечения, хранения и управления репозиториями исходного кода приложений с помощью системы контроля версий Git. Область применения Программы: разработка программного обеспечения. Программа обеспечивает выполнение следующих функций: хранение на своих серверах всей истории изменений исходного кода; проверка на наличие нового кода; изменения, записанные в файл или набор файлов, позволяющие вернуться к определённой версии этих файлов; сервис позволяет хранить код в публичном и приватном пространствах. Для управления репозиториями предусмотрена работа нескольких участников с гибкой настройкой прав доступа для пользования сервисом.
Программное обеспечение защищено законодательством Российской Федерации от несанкционированного использования.
Программное обеспечение распространяется через сеть авторизованных Партнеров.
Лицензионное соглашение с конечным пользователем (EULA) по использованию ПО доступно для ознакомления на сайте: https://gitflic.ru/docs/license-sh .
3. Лицензирование
Вариант лицензирования «Локальный»
Решение для установки на собственный Узел Пользователя. Продукт предназначен для хранения кода и работы с ним в контуре Пользователя.
Количество Узлов, на котором может быть установлено ПО, не ограничено.
Модель лицензирования зависит от выбранной редакции ПО.
Редакция «Корпоративная стандартная»
Лицензия предоставляет доступ к ПО, установленному на Узле. Количество необходимых Лицензий зависит от количества учетных записей, к которым должны иметь доступ Работники Пользователя, использующие ПО. Пользователь должен приобрести то количество Лицензий, которое будет соответствовать общему количеству учетных записей Работников, использующих ПО.
У Пользователя есть возможность переназначения на новых Работников учетных записей самостоятельно.
Лицензия в варианте лицензирования «Локальный» предоставляется в коммерческом и безвозмездном исполнении. Безвозмездная Лицензия предоставляется путем скачивания дистрибутива ПО с официального сайта Компании и подходит для open source проектов и небольших команд, а также для ознакомительных целей.
Коммерческая Лицензия подходит для работы в команде более 5 человек.
Минимальный порог приобретения – 5 Лицензий для первого заказа. Условия минимального заказа не применяются в случае дополнительного заказа при наличии Лицензий или при продлении Лицензий на новый срок.
Редакция «Атлас»
Количество необходимых Лицензий зависит от количества Узлов, на которых будет установлено ПО. Пользователь должен приобрести то количество Лицензий, которое будет соответствовать общему количеству Узлов, на которых будет установлено ПО. 1 Лицензия может предоставлять право на использование ПО на 1 или 3 Узлах, в зависимости от выбранной Лицензии.
4. Срок действия лицензий
Лицензии предоставляются на ограниченный срок (срочная Лицензия). Различают Лицензии на 6, 12, 24 и 36 месяцев. По истечении соответствующего периода Лицензия на ПО прекращает свое действие. Для возобновления действия Лицензии Пользователь должен приобрести Лицензию на новый период.
5. Обновления
Лицензии могут предоставляться с включенными Обновлениями. Политика о выпуске Обновлений доступна на официальном сайте Компании https://gitflic.ru/ .
Для срочных Лицензий срок действия Обновлений равен сроку действия Лицензии: 6, 12, 24 или 36 месяцев.
Компания предоставляет Обновления к ПО в рамках сертификата на Обновление в соответствии с Политикой о выпуске обновлений.
6. Ознакомительные версии
Конечный пользователь может запросить Программное обеспечение для ознакомления и тестирования, такое ПО обозначается как Ознакомительная версия и предоставляется на безвозмездной основе в соответствии с Разделом 4 Лицензионного соглашения с Конечным пользователем. Функциональность программного обеспечения может быть ограничено.
Количество дней на ознакомление и тестирование не должно превышать 90 календарных дней. По истечении срока действия ознакомительной версии ПО, Конечный пользователь обязан либо приобрести Лицензии на Программное обеспечение, либо уничтожить все копии используемого ПО.
7. Способы распространения
Программное обеспечение распространяется в соответствии с лицензионным договором. Дистрибутив ПО передаётся в электронной форме.
