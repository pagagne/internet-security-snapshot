## Fix-date sources test (author's decision: test all four groups on Q3)
- New private Research task `fixdate_sources` (e4dce5d; checks pass) tried four groups on the
  flaws first added to CISA KEV in Q3 2026: OSV and GitHub advisories, deps.dev release dates,
  vendor CSAF feeds, Debian and Ubuntu notices. Results and Claude's reading in the private
  repository; method findings only here:
  1. GitHub advisory "published" dates look like coverage but are not fix dates: GitHub mirrors
     every CVE as an advisory on the day it is published. Must not be used as a fix source.
  2. Real gains are small: OSV fixing commits, deps.dev release dates and dates written in
     advisory links each date a few flaws that had none.
  3. Debian and Ubuntu add nothing for this list (it is mostly commercial appliances), and
     almost no vendor on the list publishes CSAF provider metadata.
  4. The practice evaluation over-counted assumed dates because the frozen bundle lacks the CVE
     record's disclosure date (datePublic), which the production worksheet does use.
  5. Conclusion: the commercial-vendor gap stays with the author's hand check.
- **Decision (author):** add the three small sources to the automatic pre-fill and fix the
  bundle. Done: the pre-fill for exploited flaws now tries, after the vendor sources, an OSV
  fixing commit, the deps.dev release date of the first patched version (reviewed GitHub
  advisories only), and a full date written in an advisory or bulletin link; then the CNA
  disclosure date; then the assumed publication date. GitHub's global advisory "published" date
  is never used. The CVE collector now keeps the disclosure date (`date_public`) in the frozen
  bundle, and the practice evaluation passes it on. Every new date except deps.dev is marked for
  the hand check. Re-test started on the same flaws (private).
- **Re-test result (method terms; figures private):** the new pre-fill works as tested. Every
  flaw the three sources could date now gets that date automatically, a few flaws that had only
